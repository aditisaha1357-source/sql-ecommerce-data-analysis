# SQL E-Commerce Data Analysis

## Project Overview

This project is an E-Commerce Data Analysis project developed using SQL and MySQL. The main purpose of this project is to analyze customer, order, product, sales, and revenue data and generate meaningful business insights.

The project consists of multiple modules covering different types of SQL-based analysis, from basic data exploration to advanced customer and sales analysis.

## Objectives

* Analyze customer purchasing behavior
* Analyze customer-wise orders and spending
* Identify top-selling products
* Analyze product and category-wise sales
* Calculate customer and product revenue
* Analyze monthly sales trends
* Perform customer segmentation based on spending
* Calculate average order value
* Identify high-value orders and customers
